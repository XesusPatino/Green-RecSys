## About

Training and serving recommender models consumes a lot of resources, yet model choice is usually driven by accuracy alone.

This project (my Bachelor's thesis) proposes a **methodology that helps developers find the configurations that maximize recommendation performance while reducing carbon footprint** in different contexts.

## What it does

- ⚙️ Trains and evaluates recommendation models under different configurations
- ⚡ Measures energy consumption and CO₂ emissions during **training and inference**
- 📊 Compares performance against footprint to identify the most efficient setups
